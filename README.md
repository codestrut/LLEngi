# LLM Engineering — Learning Journey

My notes, experiments, exercises, and implementations while learning **LLM Engineering, Generative AI, RAG, Fine-Tuning, and AI Agents**.

This repository accompanies my learning journey through the **AI Engineer Core Track: LLM Engineering, RAG, QLoRA, Agents** course by Ed Donner / Ligency.

The goal is not simply to complete the tutorials, but to understand the concepts behind modern LLM applications and eventually build production-ready AI systems independently.

## 🎯 Learning Objectives

Through this journey, I aim to develop a practical understanding of:

* Large Language Models and Generative AI
* Transformer architecture
* LLM APIs and inference
* Prompt and context engineering
* Open-source LLMs
* Hugging Face
* Local LLM deployment with Ollama
* Multimodal AI
* Embeddings and vector search
* Retrieval-Augmented Generation (RAG)
* Fine-tuning
* LoRA / QLoRA
* Model evaluation
* AI agents and tool calling
* Multi-agent systems
* LLM deployment and MLOps
